# Technical review of the Codex return and next steps

## Decision

Accept the Codex return as a reproducible CPU and engineering contribution, not a completed model study or a newly rendered submission. Finish publication engineering locally, preserve the original evidence, and direct the next compute authorization to an actual compatibility pilot and the causal-timing study. Do not add another cycle of duplicate scripted observations to the scientific denominator.

## Evidence assessment

The incoming archive contains the revised source but stale top-level report binaries, exactly as its execution report discloses. All 370 manifested files matched their archive hashes. Its 77 inherited evidence files are unchanged. Seven CPU outputs were independently regenerated here and matched byte-for-byte. The 960 scripted episodes, 375 population cases, 600 exact checks, 3,000 sampling replicates and six exact crossing computations therefore remain the same original body of evidence.

Codex's five additional tests are valuable: public refusal/truncation fields are retained, completed actions survive failed reports, full planned denominators are represented, and label testing keeps its stated orientation and correction family. Real endpoint compatibility remains unmeasured. Mock records cannot establish that a hosted model interface behaves as expected.

## New defect found and repaired

The JSON parser rejected NaN/Infinity constants but accepted numeric literals such as 1e400 because Python converted them to infinity. A finite `parse_float` callback now rejects exponent overflow recursively. The new regression test includes nested and negative variants plus valid finite controls. Eighteen tests pass. The before/after demonstrations are preserved in `verification/v7/`. Existing records were not rewritten and the change is not represented as a new scientific observation.

## Manuscript review

The v7 manuscript restores primary-source locations for previously unavailable references, narrows novelty against partial identification, and distinguishes synthetic conditional-error envelopes from externally justified deployment bounds. It preserves the target-sensitive identification interval, the explicitly conditional certification theorem, and the robustness proposition. No new theorem or proof-assistant validation is claimed.

The Codex source's nominal page breaks did not actually produce eight main pages: a repeated paragraph overflowed. Removing that duplicate, without deleting its substantive information elsewhere or shrinking fonts/margins, restored eight main pages. Native equation rendering was checked; a malformed inline supremum rendering was replaced by the equivalent words “maximum minus minimum.” The current PDF and DOCX are newly built, not renamed historical files.

## Priority order

1. Confirm exact models, endpoint permission and a single global budget; provide credentials only through the execution environment. Run the small separate provider pilot.
2. Freeze the unchanged causal question and run the bounded model study with complete outcome accounting. Strong compliance, weak detection or null behavior differences must remain reportable outcomes.
3. Obtain independent theorem/novelty review. The identification result needs its full-history and unrestricted-continuation assumptions; the certification result needs known maps, convex classes and resets. A real deployment conclusion requires additional evidence.
4. Complete author/affiliation, source metadata, artifact delivery and disclosure gates, then verify the final document again after any numerical update.

The rendered report is suitable for author review as a theory-and-mechanism submission candidate. It is not evidence of actual LLM awareness, deceptive intent, external-validity guarantees, or an accepted/submitted paper.
