# Execution report: v6

## What changed

The project question remains target-specific safe behavioral identification despite detectable simulation. This release adds a conditional-error robustness proposition, integrates prior conditional identification/certification theory into the supplied Apart Word template, implements a two-family local experiment, and packages a prospective bounded LLM study. It does not claim a new general statistical testing principle or any observed LLM behavior.

## Executed work

The release ran 960 scripted episodes, retained all of them, and checked 384 prescribed matched-input pairs. It enumerated 375 population cases and 600 exact identities/bounds. It ran 3,000 sampling replicates of128 draws each and saved every count vector. Six exact absorbing dynamic programs calculated threshold-crossing probabilities, including both faulted nominal and corrected procedures. The cached-bit counterexample was also checked.

The independent inherited v5 checkers were rerun on38 saved cases, checking2,031 rational constraints. These are rechecks of prior project results, not new model experiments. Twelve unit tests passed; two include exhaustive625-probe-sequence checks. The final mock transport smoke test completed12episodes/36mock responses. No real inference API call was made, and no credentials were read for a live run.

## Corrections during development

1. The initial scripted coherent-control branch made the blind policy constant, unlike its seeded primary behavior. It was repaired to use exactly the same seed-based policy mapping across conditions; all local experiments and tests were rerun. The pair counts and manuscript headline counts did not change.
2. Mock report-failure handling needed a request index reserved before the call. It was fixed so a failed report cannot collide with the next report's raw ledger entry.
3. Freeze manifests were extended from the runner alone to source and protocol files. HTTP redirects were disabled to prevent an approved inference request from being forwarded with authorization to another host.
4. The initial Word rendering overflowed the intended page breaks and misrendered some math delimiters. The final source uses correct editable math, shortened prose rather than smaller margins, and numbered table captions. Final references begin on page9.

## Evidence interpretation

Scripted policies and fixed diagnostics demonstrate available mechanisms, not autonomous discovery. Different replicate IDs do not turn two small worlds into hundreds of realistic tasks. The weighting experiment assumes known kernels and cannot be silently applied to an LLM using a coarse context label. Conditional-error scores require justified conditional envelopes. A corrected process with no power is inconclusive, not safe.

## Unexecuted work and author gates

All LLM measurements are unexecuted. Real-provider transport compatibility, current model availability, current pricing, and spending permission remain prerequisites. No public repository, paper submission, email, or external audit was performed. The report has an explicit affiliation placeholder and no invented artifact URL. Human theorem/novelty/source review, authorship approval, disclosure review, and current submission eligibility remain necessary. The supplied rubric requests the team's own writing; the AI assistance is explicitly disclosed.

The six-hour Codex workflow reserves the final two hours for analysis and publication checks. It is conditional on inference access and does not guarantee a positive finding or successful provider completion. Inference stops rather than overruns authorization. The default configuration has no models and blocks paid calls.
